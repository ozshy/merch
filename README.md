# merch
Data and R-code for a paper titled: "How Merchants Get Paid"

Available at: https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3618759

The are 2 data (RDS) files and an R-code.

Copy all three files to the same directory on you computer. 

Don't forget to set the working directory to the folder you are using. 

First, run the entire code!

Then, if you are using RStudio, you can jump to a specific table or figure by clicking on the relevant title on the lower-left corner.
